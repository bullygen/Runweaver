# Поиск кольцеобразных структур на изображениях сверхмассивных чёрных дыр

## 1. Научная задача

Алгоритм находит кольцеобразные компоненты на синтетических и восстановленных изображениях окрестности сверхмассивной чёрной дыры. Входное изображение представляется в виде

\[
I(x,y)=P\ast\left[B(x,y)+\sum_{j=1}^{J}A_j(x,y)\right]+\varepsilon(x,y),
\]

где \(P\) задаёт размытие и искажения восстановления, \(B\) задаёт фон, \(A_j\) задаёт кольцо, \(\varepsilon\) содержит шум и остаточные ошибки.

В реализованной модели

\[
A_j=
\frac{a_j}{2\pi}
\left[1-b_j\cos\left(\alpha-\varphi_j\right)\right]
\exp\left[-\frac{(r-R_j)^2}{\sigma_j^2}\right],
\]

\[
r=\sqrt{(x-x_{0j})^2+(y-y_{0j})^2}.
\]

Для каждого кольца определяются семь величин:

\[
\theta_j=(a_j,R_j,\sigma_j,b_j,\varphi_j,x_{0j},y_{0j}),
\]

где \(a\) — амплитуда, \(R\) — радиус, \(\sigma\) — ширина, \(b\) и \(\varphi\) — величина и направление угловой неравномерности яркости, \(x_0,y_0\) — центр.

Научное назначение алгоритма:

- проверка наличия кольцеобразной морфологии;
- измерение центра, радиуса, ширины и неравномерности яркости;
- построение каталога колец для больших библиотек численных моделей;
- оценка зависимости результата от шума, разрешения, покрытия пространственных частот, фона и временной изменчивости;
- получение начальных приближений для последующего анализа интерферометрических данных.

Результат относится к морфологии изображения. Физическое отождествление найденной структуры с фотонным кольцом требует трассировки лучей, моделирования интерферометрических видностей, ошибок калибровки, теплового шума и нескольких способов восстановления изображения.

## 2. Архитектура вычислений

Полная последовательность имеет вид

\[
\text{генерация}\rightarrow D1\rightarrow D2\rightarrow D3\rightarrow D4\rightarrow D5\rightarrow D6\rightarrow
\text{статистика}\rightarrow\text{графики}.
\]

| Шаг | Действие | Сохраняемый результат |
|---|---|---|
| Генерация | создаёт изображение, истинные параметры и составляющие сцены | `images/<id>/` |
| D1 | выделяет граничные пиксели и их веса | `D1_preprocess/<id>/d1_edges.npz` |
| D2 | строит разреженный накопитель голосов в координатах \(x_0,y_0,R\) | `D2_hough/<id>/d2_sparse_accumulator.npz` |
| D3 | выбирает конечный список кандидатов \((x_0,y_0,R)\) | `D3_candidates/<id>/d3_candidates.json` |
| D4 | вычисляет начальные значения всех семи параметров кольца | `D4_initialization/<id>/d4_initial_params.json` |
| D5 | уточняет параметры по изображению методом наименьших квадратов | `D5_fit/<id>/d5_fit.json` |
| D6 | удаляет слабые и повторные решения | `D6_prune/<id>/d6_final.json` |
| Статистика | сопоставляет найденные и истинные кольца, считает ошибки и доверительные интервалы | `statistics/` |
| Графики | показывает вход, результат каждого шага, остатки и сводные распределения | `visualization/`, `statistics/plots/` |

Модули D1–D6 имеют устойчивый смысл:

\[
\text{границы}\rightarrow\text{геометрические голоса}\rightarrow\text{кандидаты}\rightarrow
\text{начальное приближение}\rightarrow\text{уточнение}\rightarrow\text{окончательный отбор}.
\]

Реализацию каждого шага можно заменять и дополнять. Новый вариант должен сохранять смысл шага и формат данных для следующего модуля. В коде варианты задаются полями `PipelineConfig`, аргументами командной строки и функциями `process_one`.

### Настройка

Все числовые и логические параметры задаются:

- в `smbh_cv_pipeline/config.py`;
- в файле, переданном через `--config`;
- аргументами командной строки, которые имеют наивысший приоритет;
- в планах `experiments/article_v1/*.json` для серии опытов.

Каждый запуск сохраняет фактически использованную конфигурацию в `config_used.json`. Начальное число датчика псевдослучайных чисел задаётся через `seed`, поэтому одинаковые входные данные и параметры воспроизводят одинаковый результат.

### Параллельные вычисления

Изображения внутри одного шага обрабатываются независимыми процессами. Число процессов задаётся отдельно:

```text
workers_generate, workers_d1, workers_d2, workers_d3,
workers_d4, workers_d5, workers_d6, workers_viz
```

Обычный запуск по умолчанию использует один процесс. Текущий план `article_v1` задаёт для D1–D6 соответственно \(8,8,8,8,6,8\) процессов. Для тяжёлого плотного варианта D3 код оценивает требуемую память и ограничивает число процессов. При нескольких процессах один дочерний процесс выполняет одно изображение, что ограничивает накопление памяти во внешних численных библиотеках.

### Продолжение после остановки

Каждый шаг пишет результат на диск, поэтому `d1`, `d2`, ..., `stats`, `viz` можно запускать отдельно после появления требуемых входных файлов.

Исполнитель серии опытов проверяет наличие результата каждого шага для каждого изображения. Повторная команда начинает работу с первого отсутствующего результата. Файл `run_signature.json` содержит отпечаток выборки, список изображений, этап, начальное число и полную конфигурацию. При несовпадении отпечатка продолжение блокируется. Аргумент `--restart` удаляет каталоги расчётов, выбранных текущей командой, и создаёт их заново.

### Журналирование

В терминал выводятся время, уровень сообщения, начало и конец шага, число готовых изображений и ход обработки. Уровень задаётся через `--log-level`.

Структурированный журнал содержит:

- `runtime/<stage>_stage_summary.json` — время шага, число процессов и обработанных изображений;
- `runtime/per_image_runtime_memory.jsonl` — время, начальную, конечную и наибольшую занятую память для каждого изображения;
- `experiment_metadata.json` — этап, вариант параметров, начальное число и выборку;
- `statistics/summary.json` и таблицы `statistics/*.csv` — измеренные результаты.

Основная точка запуска:

```bash
.venv/bin/python smbh_cv_run.py all \
  --config experiments/article_v1/base_pipeline_config.json \
  --out runs/example \
  --n-images 1 \
  --workers-generate 1 \
  --workers-d1 1 --workers-d2 1 --workers-d3 1 \
  --workers-d4 1 --workers-d5 1 --workers-d6 1 \
  --make-plots
```

## 3. План экспериментов

### Значение этапов

В текущем алгоритме обучаемые веса отсутствуют. Подбор относится к числовым порогам, размерам областей, числу голосов и правилам удаления колец.

- `validate` проверяет файлы выборки: размеры, конечность чисел, контрольные суммы, уникальность сцен и отсутствие общей сцены в разных частях.
- `search` обозначает всю процедуру выбора числовой конфигурации.
- `smoke` запускает один вариант на одном изображении и проверяет исправность вычислительной цепи.
- `screening` выполняет первичный широкий поиск на малой части рабочей выборки.
- `promotion` повторно вычисляет шесть лучших вариантов на большем числе изображений и двух последовательностях псевдослучайных чисел.
- `validation` сравнивает три оставшихся варианта на отдельной контрольной выборке. Лучший вариант после этого фиксируется.
- `test` один раз измеряет качество фиксированного варианта на независимой выборке в пределах исходных условий.
- `verification` измеряет качество того же варианта при заранее заданных выходах за исходные условия.

Результаты `test` и `verification` не участвуют в подборе параметров. Изменение конфигурации после их просмотра требует новой версии протокола и новой итоговой выборки.

### Генерация выборки

Набор `article_v1` содержит 1900 независимо созданных изображений \(256\times256\). Для каждой сцены записаны отдельные `family_id`, начальное число и контрольная сумма SHA-256. Проверка `datasets/article_v1/validation_report.json` подтверждает 1900 различных семейств, 1900 различных массивов и отсутствие ошибок целостности.

| Часть | Начальное число | Изображений | С кольцами | Без колец | Назначение |
|---|---:|---:|---:|---:|---|
| `development` | 110000 | 600 | 480 | 120 | подбор параметров |
| `validation` | 220000 | 300 | 240 | 60 | выбор из трёх вариантов |
| `test` | 330000 | 500 | 375 | 125 | итоговая оценка в исходной области |
| `verification` | 440000 | 500 | 340 | 160 | проверка расширенной области |

Положительная сцена содержит от 1 до 12 колец:

\[
P(1\ldots3)=0.30,\qquad P(4\ldots7)=0.45,\qquad P(8\ldots12)=0.25.
\]

Для `development`, `validation` и `test` циклически уравновешиваются и затем независимо перемешиваются следующие величины:

| Величина | Значения |
|---|---|
| Отношение сигнала к шуму | \(3,5,10,20,40\) |
| Шум | независимый нормальный, коррелированный нормальный с длиной связи 2 пикселя |
| Постоянный фон | \(0,0.001,0.003,0.006\) |
| Градиент фона | \(0,0.002,0.006\), направление случайное |
| Вид фона | струя, два пятна, гладкий диск, турбулентное поле |
| Полная ширина аппаратного размытия на половине высоты | \(0,2,4,8\) пикселей |
| Покрытие пространственных частот | полное, разреженное подобие EHT, более плотное подобие ngEHT |
| Временная изменчивость | \(0,0.03,0.08\), усреднение восьми кадров |
| Радиальный профиль | гауссов, лоренцев, переменной ширины, неполное кольцо |
| Область параметров | внутренняя часть допустимого интервала, его границы |
| Расположение колец | случайное, сгруппированное |
| Помеха без кольца | пятна, узлы струи, диск, серп, короткие дуги, турбулентное поле |

Шум выбирается из условия

\[
\mathrm{ОСШ}=
\frac{\sqrt{\frac{1}{N}\sum_{p=1}^{N}S_p^2}}
{\sqrt{\frac{1}{N-1}\sum_{p=1}^{N}(\varepsilon_p-\bar\varepsilon)^2}},
\]

где \(S_p\) — кольцевая составляющая после размытия и преобразования пространственных частот. Для сцены без кольца масштаб шума определяется по скрытому кольцу, которое в изображение не добавляется.

Проверочная часть состоит из пяти блоков по 100 изображений:

1. ОСШ \(1.5,2,60\) и усиленный фон.
2. Новые виды разреженного покрытия и размытие до 12 пикселей.
3. Изменчивость \(0.15,0.25\), эллиптические кольца и профиль с плоской вершиной.
4. Выход \(R,\sigma,A,x_0,y_0\) за интервалы уточнения.
5. Только сцены без колец при совместном действии тяжёлых искажений.

Преобразование пространственных частот является моделью в области изображения. Оно не включает координаты отдельных станций, ошибки усиления и фазы, тепловые ошибки видностей, CLEAN и регуляризованное восстановление.

### Прохождение выборки

План создаёт исходную конфигурацию `baseline` и 24 варианта равномерного заполнения многомерной области: 4 независимых начала по 6 вариантов.

| Этап | Варианты | Изображения на вариант | Начальные числа алгоритма | Ограничения вычислений |
|---|---:|---:|---|---|
| `smoke` | 1 | 1 из `development` | 239 | до 20000 голосов D2, до 50 вычислений D5 |
| `screening` | 25 | 60 из `development` | 239 | до 120000 голосов D2, до 250 вычислений D5 |
| `promotion` | 6 лучших | 240 из `development` | 239, 991 | до 250000 голосов D2, до 600 вычислений D5 |
| `validation` | 3 лучших | все 300 из `validation` | 239, 991 | до 300000 голосов D2, до 1000 вычислений D5 |
| `test` | 1 фиксированный | все 500 из `test` | 239, 991, 2027 | полная конфигурация |
| `verification` | тот же вариант | все 500 из `verification` | 239, 991, 2027 | полная конфигурация |

Повторные начальные числа меняют случайные тройки точек в D2. Они не создают новые независимые изображения.

В поиске сохраняются семейства методов D1–D6 и меняются 15 числовых величин:

| Модуль | Интервалы поиска |
|---|---|
| D1 | перцентиль яркой области \(99.2\ldots99.9\), допустимая доля граничных пикселей \(0.04\ldots0.10\) |
| D2 | доля голосов \(0.18\ldots0.38\), площадь треугольника \(8\ldots30\), число секторов \(8\ldots18\) |
| D3 | квантиль повторных выборок \(0\ldots0.35\), расстояния подавления \(3\ldots8\) и \(2\ldots7\), число кандидатов \(12\ldots20\) |
| D4 | полуширина полосы \(3\ldots7\), радиальное окно \(7\ldots14\) |
| D5 | масштаб функции потерь \(0.3\ldots2.0\) по логарифмической сетке |
| D6 | порог амплитуды \(0.008\ldots0.020\), порог \(\Delta BIC\) \(1000\ldots15000\) по логарифмической сетке, расстояние объединения \(3\ldots9\) |

Варианты упорядочиваются по величине

\[
Q=
\min_s F_{1,\;0.025}^{(s)}
-0.25\,\operatorname{std}_s(F_1)
-0.05\,\max_s \mathrm{ЛСИ}^{(s)},
\]

где \(F_{1,\;0.025}\) — нижняя граница 95%-го доверительного интервала, ЛСИ — число ложных колец на одно изображение без истинных колец. При точности положительных решений ниже 0.80 или полноте ниже 0.70 из \(Q\) вычитается 1.

## 4. Шесть вычислительных модулей

### D1. Границы

D1 преобразует изображение \(I\) в двоичную карту \(B\) и карту весов \(W\).

Варианты маскирования яркой фоновой компоненты:

- `none` — без маскирования;
- `rect_max` — квадрат около самого яркого пикселя заменяется медианой;
- `percentile_cc` — маскируется связная яркая область с наибольшим суммарным потоком.

Варианты граничного оператора:

- `legacy_laplace_positive` — знаковый дискретный лапласиан по четырём соседям;
- `log_mad` — максимум модулей лапласиана после гауссова сглаживания на нескольких масштабах;
- `dog` — разность двух гауссовых сглаживаний;
- `sobel` — \(\sqrt{I_x^2+I_y^2}\);
- `laplace_sign` — положительная часть библиотечного лапласиана.

Варианты порога:

\[
T_{\mathrm{mad}}=\operatorname{med}E+
\tau\cdot1.4826\,\operatorname{med}|E-\operatorname{med}E|.
\]

- `positive` использует \(T=0\);
- `mad` использует формулу выше;
- `percentile` использует заданный перцентиль;
- `sauvola` использует локальный порог.

После порога доступны `none`, удаление малых компонент `remove_small`, открытие с закрытием `open_close`, повторное открытие с контролем доли пикселей `legacy_control_open`, а также утончение линий до скелета.

Конфигурация `article_v1`: `percentile_cc`, `legacy_laplace_positive`, `positive`, `legacy_control_open`, утончение включено.

### D2. Голосование за окружности

D2 случайно выбирает три граничные точки, проводит через них окружность и добавляет голос в ячейку \((x_0,y_0,R)\). Число принятых голосов

\[
N_v=\min\left(N_{\max},f_v\min(n_x,n_y)^3\right).
\]

Варианты:

- `sparse_rht` — точки выбираются из всей граничной карты;
- `sparse_rht_stratified` — точки выбираются из разных угловых секторов.

Вес голоса равен \(1\), \((w_1+w_2+w_3)/3\) или \(w_1w_2w_3\) для `none`, `mean`, `product`. Настраиваются число голосов, минимальная площадь треугольника, шаги сетки центра и радиуса, пределы радиуса и число секторов.

Накопитель хранит только занятые ячейки:

\[
\text{память}=O(K),
\]

где \(K\) — число ячеек с ненулевым голосом.

Конфигурация `article_v1`: `sparse_rht_stratified`, `mean`, \(R=30\ldots115\) пикселей.

### D3. Кандидаты

D3 получает строки \((x_0,y_0,R,q)\), отбрасывает слабые максимумы и подавляет близкие решения:

\[
\sqrt{(x_i-x_j)^2+(y_i-y_j)^2}\le d_c,\qquad |R_i-R_j|\le d_R.
\]

Варианты:

- `peak_nms` — сортировка по \(q\), порог и подавление близких максимумов;
- `bootstrap_nms` — порог по повторным выборкам с возвращением;
- `ph_safe_proxy` — безопасная обработка лучших разреженных ячеек с оценкой памяти плотного массива;
- `ph_union_find_sparse` — устойчивость компонент связности на разреженном накопителе;
- `ph_cripser_dense` — плотный кубический комплекс через дополнительную библиотеку `cripser`.

Для устойчивости компонент используется

\[
p=q_{\mathrm{birth}}-q_{\mathrm{death}}.
\]

Чем больше \(p\), тем дольше максимум остаётся отдельной компонентой при снижении уровня. Порог задаётся долей максимума `relative`, квантилем `quantile` или квантилем максимумов повторных выборок `bootstrap`.

Настраиваются порог, число повторов, расстояния подавления, предел числа кандидатов, число лучших разреженных ячеек и предел памяти.

Конфигурация `article_v1`: `ph_union_find_sparse`, `bootstrap`, не более 15 кандидатов.

### D4. Начальные параметры

D4 дополняет \((x_0,y_0,R)\) величинами \(a,\sigma,b,\varphi\).

- `constants` задаёт \(a=0.035,\sigma=7,b=0.5,\varphi=0\).
- `profile_harmonic` уточняет радиус по максимуму медианного радиального профиля, ширину по ширине на половине высоты, а \(b,\varphi\) — по первой угловой гармонике.

\[
R=\arg\max_r P(r),\qquad
\sigma=\frac{\mathrm{ПШПВ}}{1.665109222},
\]

где ПШПВ — полная ширина профиля на половине высоты.

\[
C=\sum_\alpha v(\alpha)\cos\alpha,\quad
S=\sum_\alpha v(\alpha)\sin\alpha,\quad
\varphi=\operatorname{atan2}(S,C)+\pi,
\]

\[
b=\frac{2\sqrt{C^2+S^2}}{\sum_\alpha v(\alpha)}.
\]

Амплитуда оценивается по 95-му перцентилю яркости кольцевой полосы:

\[
a=\frac{2\pi\,\operatorname{perc}_{95}v}{1+b}.
\]

Настраиваются полуширина кольцевой полосы, радиальное окно, число угловых отсчётов и число передаваемых кандидатов.

Конфигурация `article_v1`: `profile_harmonic`, полоса 4 пикселя, окно 10 пикселей, 96 угловых отсчётов.

### D5. Уточнение параметров

D5 минимизирует взвешенные остатки

\[
r_p=w_p\frac{M_p-I_p}{s_\varepsilon}
\]

с ограничениями на параметры. Реализован вычислитель `scipy` на основе `least_squares`.

Функции потерь:

- `linear` — сумма квадратов;
- `soft_l1`, `huber`, `cauchy`, `arctan` — уменьшают влияние больших остатков по разным законам.

Веса:

- `uniform` — \(w_p=1\);
- `ring_support` — \(w_p=1\) около начальных колец и \(w_p=0.25\) вдали от них;
- `inverse_background` — \(w_p=1/\sqrt{B_p+10^{-6}}\).

Настраиваются число вычислений функции, совместное уточнение фона, масштаб функции потерь и шаг разрежения пикселей. Поле `d5_local_then_global` зарезервировано и на результат пока не влияет.

D5 оценивает стандартные ошибки параметров по линейному приближению матрицы производных. Для нелинейных функций потерь эти ошибки служат диагностикой.

Конфигурация `article_v1`: `scipy`, `soft_l1`, `ring_support`, шаг 8, до 1000 вычислений.

### D6. Окончательный отбор

D6 получает уточнённые кольца и применяет один из восьми вариантов:

- `none` — сохранить все;
- `amplitude` — оставить \(a\ge a_{\min}\);
- `delta_bic` — оставить кольца с достаточным улучшением модели;
- `merge_delta_bic` — объединить повторы, затем применить \(\Delta BIC\);
- `fdr_bh_amplitude` — проверить значимость амплитуд процедурой Бенджамини–Хохберга;
- `merge_fdr_bh_amplitude` — объединить повторы, затем проверить амплитуды;
- `amplitude_merge_delta_bic` — порог амплитуды, объединение, затем \(\Delta BIC\);
- `amplitude_merge_fdr_bh_amplitude` — порог амплитуды, объединение, затем проверка амплитуд.

Используется приближение разности байесовского информационного критерия

\[
\Delta BIC=
N\ln\frac{RSS_{\mathrm{без\ кольца}}}{RSS_{\mathrm{полная}}}
-7\ln N.
\]

Здесь \(RSS\) — сумма квадратов остатков.

Два кольца объединяются при

\[
\|c_i-c_j\|\le d_c,\qquad |R_i-R_j|\le d_R.
\]

Для проверки амплитуды

\[
z_i=\frac{a_i}{s_{a_i}},\qquad p_i=P(Z\ge z_i),
\]

после чего применяется правило Бенджамини–Хохберга

\[
p_{(k)}\le\alpha\frac{k}{m}.
\]

При отсутствии оценки ковариации доступны `keep_all`, `amplitude`, `drop_min_amplitude`. Настраиваются минимальное число колец, пороги амплитуды и \(\Delta BIC\), уровень \(\alpha\), расстояния объединения и действие при отсутствии ковариации.

Конфигурация `article_v1`: `amplitude_merge_delta_bic`, \(a_{\min}=0.0125\), \(\Delta BIC>7000\), \(d_c=d_R=6\) пикселей.

## 5. Решение о годности

Истинное и найденное кольца считаются совпавшими при одновременном выполнении

\[
\frac{\|\hat c-c\|}{R}\le0.15,\qquad
\frac{|\hat R-R|}{R}\le0.15,\qquad
\frac{|M\cap\hat M|}{|M\cup\hat M|}\ge0.10.
\]

После взаимно однозначного сопоставления считаются:

\[
\mathrm{точность}=
\frac{N_{\mathrm{верно}}}
{N_{\mathrm{верно}}+N_{\mathrm{лишнее}}},
\qquad
\mathrm{полнота}=
\frac{N_{\mathrm{верно}}}
{N_{\mathrm{верно}}+N_{\mathrm{пропущено}}},
\]

\[
F_1=\frac{2\,\mathrm{точность}\,\mathrm{полнота}}
{\mathrm{точность}+\mathrm{полнота}}.
\]

Здесь \(N_{\mathrm{верно}}\) — число правильно найденных колец, \(N_{\mathrm{лишнее}}\) — число лишних колец, \(N_{\mathrm{пропущено}}\) — число пропущенных колец.

Дополнительно используются

\[
\mathrm{ЛСИ}=
\frac{\sum N_{\mathrm{лишнее}}\ \text{на изображениях без колец}}
{N_{\text{изображений без колец}}},
\]

\[
\mathrm{ДЛИ}=
\frac{\#\{\text{изображения без колец с }N_{\mathrm{лишнее}}>0\}}
{N_{\text{изображений без колец}}}.
\]

95%-е доверительные интервалы строятся повторными выборками изображений с возвращением. Единицей повторной выборки служит изображение, поскольку кольца одной сцены зависимы.

Назначение величин:

- точность ограничивает долю ложных колец среди найденных;
- полнота ограничивает долю пропущенных истинных колец;
- \(F_1\) требует одновременно высокой точности и полноты;
- ЛСИ и ДЛИ непосредственно измеряют ложные срабатывания на сценах без колец;
- нижние границы доверительных интервалов учитывают случайную неопределённость;
- наихудший заранее заданный срез выявляет слабость при отдельном ОСШ, фоне, размытии, профиле или области параметров.

### Сильная годность в проверенных условиях

Все условия должны выполняться одновременно:

| Итоговая выборка | Условие |
|---|---:|
| `test` | нижняя граница точности \(\ge0.90\) |
| `test` | нижняя граница полноты \(\ge0.82\) |
| `test` | нижняя граница \(F_1\ge0.85\) |
| `test` | верхняя граница ЛСИ \(\le0.10\) |
| `test` | нижняя граница \(F_1\) наихудшего среза \(\ge0.70\) |
| `verification` | нижняя граница точности \(\ge0.75\) |
| `verification` | нижняя граница полноты \(\ge0.65\) |
| `verification` | нижняя граница \(F_1\ge0.70\) |
| `verification` | верхняя граница ЛСИ \(\le0.25\) |

Также требуются не менее 500 изображений и 100 изображений без колец в каждой из частей `test` и `verification`.

### Ограниченная годность

Если сильный уровень не достигнут, проверяются оценки без доверительных границ:

\[
\mathrm{точность}_{test}\ge0.85,\quad
\mathrm{полнота}_{test}\ge0.75,\quad
F_{1,test}\ge0.80,
\]

\[
\mathrm{ЛСИ}_{test}\le0.25,\quad
F_{1,verification}\ge0.60,\quad
\mathrm{ЛСИ}_{verification}\le0.50.
\]

Программа `smbh_cv_quality.py` выдаёт один из четырёх кодов:

| Код | Смысл |
|---|---|
| `article_ready_strong_under_tested_conditions` | сильная годность в объявленных синтетических условиях |
| `promising_but_limited` | ограниченная годность |
| `experimental_not_yet_robust` | диагностический результат, устойчивость недостаточна |
| `insufficient_evidence` | отсутствуют необходимые объёмы или конечные величины |

Годность относится к обнаружению кольцеобразной морфологии в объявленных условиях. Утверждение о физическом фотонном кольце требует отдельной проверки на интерферометрических видностях и физических моделях.
