# Tutorials

Each tutorial has a Jupytext-paired `.py` and `.ipynb` file. The script is the
CI execution source; the notebook contains the same cells.

1. Minimal sequential synthetic regression.
2. Process-parallel partitions, partial failure and resume.
3. Custom I/O and serializer.
4. PyTorch training and checkpoint state.
5. Cooperative pause and durable resume.
6. Latin-hypercube DOE.
7. Optuna adaptive HPO/pruning.
8. Elite zoom next round.
9. Multi-objective Pareto selection.
10. Custom plugin contracts.
11. Prefect, Ray and MLflow adapters.
12. Article v1/v2 image workflow migration.

Commands and expected evidence are in `tutorials/EXPECTED_RESULTS.md`.
