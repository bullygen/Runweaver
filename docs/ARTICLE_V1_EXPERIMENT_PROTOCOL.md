# Протокол эксперимента article_v1

## Назначение

article_v1 проверяет полный алгоритм D1–D6 при одном совместном подборе численных параметров. План сохранен для воспроизводимости уже начатой серии. Новые способы поиска параметров реализованы отдельно как article_v2.

Используется набор `datasets/article_v1`:

| Часть | Число изображений | Назначение |
|---|---:|---|
| разработка | 600 | подбор параметров |
| отбор | 300 | выбор одной конфигурации |
| испытание | 500 | итоговая оценка |
| проверка переноса | 500 | условия вне области подбора |

Состав набора и правило генерации приведены в `docs/DATASET_ARTICLE_V1.md`.

## Поиск параметров

Первая ступень содержит

\[
N=1+4\cdot 6=25,
\]

где 1 — исходная конфигурация, 4 — число независимых начал, 6 — число точек латинского гиперкуба на одно начало.

Все 25 конфигураций проходят 60 изображений разработки при одном зерне генератора случайных чисел. Затем 6 лучших проходят 240 изображений при двух зернах. Три лучших переходят на 300 изображений отбора.

В article_v1 одновременно меняются параметры D1–D6. Поэтому результат не позволяет точно разделить вклад ранних и поздних ступеней. Пространство содержит `d2_votes_fraction`, хотя при действующих ограничениях число голосов обычно определяется `d2_max_votes`. Это одна из причин создания article_v2.

## Показатель упорядочения

Для каждого зерна вычисляются точность \(P\), полнота \(R\), гармоническое среднее

\[
F_1=\frac{2PR}{P+R}
\]

и число ложных объектов на пустое изображение \(L_0\).

В article_v1 применена оценка

\[
Q=\min F_{1,\;0.025}-0.25\,s(F_1)-0.05\max L_0.
\]

При \(P<0.80\) или \(R<0.70\) из \(Q\) вычитается 1. Эта разрывная добавка сохранена только для воспроизводимости article_v1. В article_v2 используются отдельный допуск, слои Парето и непрерывные штрафы за величину нарушения.

## Порядок этапов

1. `smoke` проверяет запуск на одном изображении.
2. `screening` сравнивает 25 конфигураций на 60 изображениях разработки.
3. `promotion` сравнивает 6 конфигураций на 240 изображениях и двух зернах.
4. `validation` выбирает одну из 3 конфигураций на 300 изображениях отбора.
5. `freeze` записывает неизменяемую конфигурацию.
6. `test` один раз оценивает ее на 500 испытательных изображениях.
7. `verification` проверяет ее на 500 изображениях вне области подбора.
8. `smbh_cv_quality.py` сопоставляет результат с заранее записанными порогами.

Команды приведены в `docs/ARTICLE_V1_EXPERIMENT_COMMANDS.md`.

## Правила независимости

- Разработка разрешена только по части `development`.
- На части `validation` выбирается одна конфигурация из заранее отобранных трех.
- После записи `experiments/article_v1/frozen_config.json` параметры не меняются.
- `test` и `verification` не используются для нового подбора.
- Повторный запуск без `--restart` продолжает незавершенный расчет.
- `--restart` удаляет выход выбранного прогона и начинает его заново.

## Область применимости результата

Итогом считаются только показатели замороженной конфигурации на `test` и `verification`. Результаты старых 24 идеальных изображений и результаты частей `screening` и `promotion` описывают разработку алгоритма.

Набор моделирует изображения после приближенного преобразования Фурье. Он не моделирует полный измерительный тракт интерферометра, ошибки станций и независимые способы восстановления изображения.
