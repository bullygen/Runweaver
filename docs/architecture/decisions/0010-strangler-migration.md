# ADR 0010: Migrate with a strangler pattern

Status: accepted

## Context

The prototype mixed reusable orchestration with correct domain computations and
filesystem contracts. A big-bang rewrite would hide behavior changes.

## Decision

Audit and characterize first, map mechanisms to Runweaver, recreate the
article workflow as an executable public-API tutorial, then remove legacy code
under the user's explicit replacement authorization.

## Alternatives

Keep two orchestrators indefinitely; silently rewrite scientific mathematics.

## Consequences

Architectural behavior remains traceable. Exact numerical detector parity is
explicitly not claimed after legacy removal.
